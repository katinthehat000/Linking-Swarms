Write the name and path of the initial condition file on the top line

An initial condition file must contain:

1) W0, a 3N x n array. N is the number of filaments, n is the number of discrete points along each filament. Each 3 x n array in W0 is a separate filament, e.g. rows 1-3 are filament 1, rows 4-6 are filament 2, etc. For good results, the spacing of points along each filament should be the constant and equal to 2h for each filament (h is the filament radius)
